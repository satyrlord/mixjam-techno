# Folded Metal artwork

Folded Metal is the artwork of the Vintage theme. No other theme uses it.
The common chassis uses folded painted metal without fasteners, fine grain,
minor scratches, dark recessed control bays, cream lettering, and pale metal
primary buttons. Each tool keeps its own color identity.

The palette values are the values of the Vintage theme.

| Palette | Chassis | Accent |
| --- | --- | --- |
| Utility | `#3c4140` | `#e79331` |
| Marine | `#20535b` | `#55aeb7` |
| Granite | `#34393c` | `#adbabd` |
| Red | `#9a2d27` | `#eb7468` |
| Olive | `#3c4428` | `#9db25e` |
| Indigo | `#2e3660` | `#96a6ec` |

Indigo is for Mastering, which has no original window to take a color from.

The current generated chassis is at
`local-data/artwork/folded-metal/chassis-screwless.png`. `provenance.json`
records the SHA-256, crop, palette values, and prepared dimensions of the active
source. The built-in image-generation tool made that source. The material slices
keep its actual grain, scratches and highlights. Recoloring changes the painted
material and keeps the neutral exposed metal details. The application does not
stretch a full-window bitmap at runtime.

At 100%, each palette has these patches:

- four 112 by 64 corner patches
- two 192 by 12 horizontal edge strips
- two 12 by 96 vertical edge strips

All material boundaries fade to zero alpha. This applies to both ends of
repeated strips. Four logical pixels at the outer edges stay fully transparent.
Continuous antialiased native rounded paths draw the outline and folded bevel.
Source silhouettes and tile joins therefore cannot produce a broken window edge.
If the corner patches collapse, they blend through alpha overlap. The window
does not cut them at its midpoint. This is the one prepared size, and 100% is
the only display scale in scope. Every image pixel paints one physical screen
pixel. Clipping supports smaller windows.

Each palette also has a static monochromatic Gaussian paint-grain tile of
256 by 256 pixels.
The deterministic quantized distribution has an exact zero mean and a measured
standard deviation of approximately 1.526 RGB levels. Every pixel gets the same
offset in all three color channels. The approved paint hue and mean color
therefore stay the same. The tile stays fixed at runtime and does not shimmer.
Its opacity dissolves over 12 logical pixels before the continuous outer bevel.
The texture does not reach the silhouette and does not create a hard inset
rectangle. `provenance.json` records the seed, distribution, dimensions, and
measured statistics. The asset check compares exact regenerated bytes. The Rust
check verifies mean, variance, Gaussian fourth moment, and matching channel
offsets.

Shared 36 by 36 rotary caps and 48 by 24 primary-button grain tiles are original
procedural control artwork. The tool renders knobs at eight times each target
size, then reduces them once with premultiplied-alpha Lanczos filtering. This
antialiases the silhouette and grip details without runtime scaling.
Interaction, text, focus, position indicators and inset panel borders remain
native controls.

Prepare assets with `python tools/assets/render-folded-metal.py`. To verify the
prepared images and source provenance without changes, run
`python tools/assets/render-folded-metal.py --check`. Preparation and
verification need the private original. Running the application does not need
it.
