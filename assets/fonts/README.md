# Native Space Grotesk fonts

These static TrueType fonts are derived offline from the preserved
`@fontsource-variable/space-grotesk` 5.3.0 package in
`assets/donors/ravefold/fonts/space-grotesk/`. Original donor files are unchanged.
The preserved RaveFold source commit is
`5965621be6ac2ea5330db9fb231755860617a285`.

Each face is instantiated at a fixed weight: Regular 400, Medium 500, or Bold 700.
Each weight retains the Latin, extended Latin, and Vietnamese subsets. Register
all three subsets in that order in each native font family. Together they include
ASCII and Romanian letters, including S and T with comma below. Keep egui's
bundled symbol fonts after these fonts as fallbacks.

The SIL Open Font License 1.1 and original copyright notice are in `LICENSE`.
Keep this notice with the application and its embedded font assets. The source
license declares no Reserved Font Name. These derived fonts retain that license.
This directory does not contain assets copied from an installed system font.

Regenerate and verify from the repository root:

```powershell
python tools/assets/prepare-fonts.py
python tools/assets/prepare-fonts.py --check
```

The script requires `fonttools[woff]==4.66.1` and `Brotli==1.2.0`. It performs no
network access. `manifest.json` records source and output SHA-256 hashes. The
check compares exact generated bytes, static weights, font names, and combined
ASCII and Romanian character coverage. Font timestamps remain fixed at the
preserved source value for reproducible output.
